# Contributing to This Project

First of all, thank you so much for considering contributing to this project! Your time and effort to help improve this app are greatly appreciated.

To make the contribution process as smooth as possible, please follow these guidelines before submitting a Pull Request (PR):

---

### 1. Test Before You Commit
Before pushing your changes or opening a PR:
* Make sure you test the application thoroughly on your local system.
* Verify that your changes work as expected and do not break any existing features.

### 2. Clear Commit Messages
When committing your changes, please write clear and descriptive commit messages:
* Explain exactly **what** you changed and **why**.
* Avoid vague messages like *"fixed bug"* or *"updated file"*. Instead, use descriptive notes like *"Fixed MDict parser issue for large files"* or *"Added UI support for custom DB databases"*.

---

Thank you again for helping make this project better!

# راهنمای مشارکت در پروژه

قبل از هر چیز، از اینکه وقت می‌ذارید و برای بهتر شدن این برنامه مشارکت می‌کنید بسیار ممنونم!

برای اینکه روند بررسی و اضافه شدن تغییرات شما روان‌تر باشه، لطفاً قبل از ارسال Pull Request (PR) موارد زیر رو رعایت کنید:

---

###  ۱. تست کامل قبل از کامیت
قبل از ارسال تغییرات:
* حتماً برنامه رو به طور کامل روی سیستم خودتون تست کنید.
* مطمئن شید که تغییرات جدید درست کار می‌کنه و باعث خرابی تو بخش‌های دیگه‌ی برنامه نشده‌ باشه.

###  ۲. توضیحات دقیق و شفاف تو کامیت‌ها
موقع ثبت (Commit) تغییرات، لطفاً پیام‌های واضح و مشخص بنویسید:
* دقیقاً توضیح دهید که **چه چیزی‌ رو** و **چرا** تغییر داید.
* از نوشتن پیام‌های مبهم مثل «رفع باگ» یا «آپدیت فایل» خودداری کنید و به جای اون توضیحات دقیق بنویسید؛ مثلاً: «رفع مشکل خوندن فایل‌های بزرگ MDict» یا «افزودن رابط کاربری برای دیتابیس‌های سفارشی».

---

باز هم بابت کمک به بهتر شدن این پروژه از شما ممنونم!
